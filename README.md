# Week 1 – Excel & Data Cleaning

## Project Overview

This project completes the Week 1 Excel & Data Cleaning practice assignment using the Global Superstore 2016 dataset.

## Tasks Completed

1. Checked and handled duplicate and missing values.
2. Created a region-wise sales summary.
3. Calculated mean, median, and mode of sales.
4. Identified the top 10 sales records and applied conditional formatting.
5. Created a category-wise revenue bar chart.

## Dataset

**Global Superstore 2016**

The dataset contains 51,290 records.

## Data Cleaning

* Duplicate rows found: 0
* Missing Postal Code values: 41,296
* Missing Postal Code values were replaced with `Not Available`.
* No records were deleted.
